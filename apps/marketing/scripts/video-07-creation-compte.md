# Vidéo 7 — Création de compte
**"Créer un compte sur Trouve Ton Nkama"**

- Format : 9:16 vertical, 1080 x 1920 px
- Durée cible : 75 à 95 secondes
- Type : vraie capture mobile de l'app en localhost
- Environnement : `http://localhost:3000`
- Page principale : `/signup`
- Objectif : montrer les deux façons de créer un compte et les deux types de profil
- Règle : ne pas produire la vidéo tant que ce script n'est pas validé

---

## Intention

Cette vidéo doit répondre simplement à la question :

> "Comment je crée un compte sur Trouve Ton Nkama ?"

On montre deux chemins :

1. inscription avec Google, puis finalisation du profil ;
2. inscription classique sans Google, avec le formulaire.

On montre aussi que les deux types d'inscription sont disponibles dans les deux méthodes :

1. **utilisateur simple** : pour chercher un logement ;
2. **annonceur** : pour publier des annonces.

Le message doit rester rassurant :

> "Vous pouvez commencer avec Google, ou créer un compte directement avec votre email."

---

## Parcours Validé

### Étape 1 — Introduction

But : annoncer le sujet.

Action écran :

1. afficher une carte courte avec le logo ;
2. texte écran : **Créer un compte** ;
3. rester environ deux secondes.

Voix off :

> "Voici comment créer un compte sur Trouve Ton Nkama."

Overlay :

> **Créer un compte**

Durée : 4 secondes.

---

### Étape 2 — Ouvrir la page d'inscription

But : montrer où commencer.

Action écran :

1. ouvrir `http://localhost:3000` ;
2. cliquer sur le bouton **S'inscrire** ;
3. attendre l'arrivée sur la page d'inscription.

Voix off :

> "Depuis la plateforme, appuyez sur S'inscrire."

Overlay :

> **S'inscrire**

Durée : 7 secondes.

---

### Étape 3 — Montrer les deux options

But : expliquer le choix sans aller trop vite.

Action écran :

1. laisser la page d'inscription visible ;
2. faire une pause sur le bouton Google ;
3. faire une pause sur le formulaire email.

Voix off :

> "Vous avez deux options : continuer avec Google, ou remplir le formulaire avec votre email."

Overlay :

> **Google ou email**

Durée : 7 secondes.

---

### Étape 4 — Montrer les deux types de compte

But : expliquer le choix du profil avant de commencer.

Action écran :

1. afficher la zone où l'utilisateur choisit son type de compte ;
2. montrer **Utilisateur simple** ;
3. montrer **Annonceur** ;
4. ne pas cliquer trop vite pour laisser lire.

Voix off :

> "Dans les deux cas, vous pouvez créer un compte utilisateur simple ou un compte annonceur."

Overlay :

> **Utilisateur ou annonceur**

Durée : 9 secondes.

---

### Étape 5 — Option 1 : commencer avec Google

But : montrer que Google sert à démarrer l'inscription.

Action écran :

1. afficher une flèche vers le bouton **Continuer avec Google** ;
2. cliquer sur le bouton ;
3. afficher l'ouverture de Google ou l'écran de choix du compte ;
4. choisir le compte Google prévu pour la démonstration ;
5. masquer l'adresse email et la photo de profil si elles apparaissent dans l'interface ;
6. attendre le retour sur Trouve Ton Nkama.

Indication montage :

- masquer l'adresse email Google partout où elle apparaît ;
- ne pas montrer de mot de passe Google ;
- ne pas montrer de code de vérification ;
- ne pas garder de plan où l'email est lisible.

Voix off :

> "Avec Google, choisissez votre compte pour commencer l'inscription."

Overlay :

> **Continuer avec Google**

Durée : 10 secondes.

---

### Étape 6 — Finaliser après Google

But : montrer qu'après Google, il reste un formulaire à compléter et qu'on peut aussi choisir annonceur.

Action écran :

1. attendre l'affichage du formulaire complémentaire ;
2. ne rien faire pendant une demi-seconde pour laisser voir l'écran ;
3. afficher le choix **Utilisateur simple** et **Annonceur** ;
4. choisir le type de compte voulu pour l'exemple filmé ;
5. remplir les champs demandés, par exemple le téléphone, le nom ou le rôle si nécessaire ;
6. valider le formulaire ;
7. attendre l'arrivée sur le compte ou le tableau de bord.

Exemple de données :

- Nom affiché : `Utilisateur Test`
- Téléphone : `066000000`
- Type de compte : `Utilisateur simple` ou `Annonceur`

Voix off :

> "Après Google, complétez le formulaire. Vous pouvez choisir utilisateur simple ou annonceur."

Overlay :

> **Compléter le profil**

Durée : 12 secondes.

---

### Étape 7 — Transition technique avant le deuxième exemple

But : préparer la deuxième démonstration sans créer de confusion.

Action hors écran :

1. supprimer le compte créé avec Google ;
2. revenir sur la page d'inscription ;
3. utiliser le même email pour l'inscription classique si possible.

Indication montage :

- cette étape ne doit pas apparaître dans la vidéo finale ;
- elle sert uniquement à pouvoir refaire une inscription propre avec le même email.

Durée vidéo : 0 seconde.

---

### Étape 8 — Option 2 : inscription sans Google

But : montrer la méthode classique, cette fois avec l'autre type de compte.

Action écran :

1. revenir sur le formulaire d'inscription ;
2. choisir le type de compte qui n'a pas été utilisé dans l'exemple Google ;
3. cliquer dans le champ nom ;
4. saisir lentement un exemple neutre ;
5. saisir l'email de démonstration ;
6. saisir un numéro de téléphone si le champ est présent ;
7. saisir un mot de passe de démonstration ;
8. cocher les conditions si nécessaire.

Exemple de données :

- Nom : `Utilisateur Test`
- Email : utiliser l'email de démonstration prévu pour la vidéo
- Téléphone : `066000000`
- Mot de passe : utiliser le mot de passe de démonstration prévu pour la vidéo
- Type de compte : utiliser l'autre choix pour montrer les deux possibilités

Voix off :

> "Sans Google, c'est le même principe : choisissez votre type de compte, puis remplissez le formulaire."

Overlay :

> **Inscription par email**

Durée : 18 secondes.

---

### Étape 9 — Valider l'inscription par email

But : montrer l'action finale.

Action écran :

1. cliquer sur le bouton d'inscription ;
2. attendre le retour visuel : succès, page suivante ou message de vérification ;
3. ne pas couper avant que l'écran soit stable.

Voix off :

> "Ensuite, validez. Votre compte est créé, ou un email de vérification vous est envoyé."

Overlay :

> **Compte créé**

Durée : 8 secondes.

---

### Étape 10 — Conclusion

But : résumer et finir avec la marque.

Action écran :

1. afficher une carte finale avec le logo ;
2. afficher le nom de la plateforme ;
3. afficher **Disponible sur tonnkama.com**.

Voix off :

> "Trouve Ton Nkama. Créez votre compte sur tonnkama.com."

Overlay :

> **tonnkama.com**

Durée : 6 secondes.

---

## Notes importantes

- Faire la vidéo en vue mobile.
- Ne pas afficher de compte Google personnel.
- La voix off doit être synchronisée avec les actions.
- Les champs doivent être remplis lentement, sans précipitation.
- Si le compte de démonstration existe déjà, utiliser un autre email `demo.creation.compte+01@ttn.ga`.
- Pour la version finale, garder les textes courts à l'écran.
- Le parcours Google doit montrer le formulaire complémentaire, car l'inscription n'est pas totalement terminée après le choix du compte Google.
- Google peut servir à créer un compte **Utilisateur simple** ou **Annonceur**.
- L'inscription sans Google peut aussi servir à créer un compte **Utilisateur simple** ou **Annonceur**.
- Pour que la vidéo reste claire, montrer un type de compte avec Google et l'autre type de compte sans Google.
- Ne pas afficher l'email Google complet dans la vidéo finale.
- Ne jamais afficher le mot de passe.
- Après la prise Google, supprimer le compte créé avant de refaire l'inscription sans Google avec le même email.
