# Vidéo 8 — Créer une annonce de maison à louer
**"Publier une maison sans assistant IA"**

- Format : 9:16 vertical, 1080 x 1920 px
- Durée cible : 65 à 85 secondes
- Type : vraie capture mobile de l'app en localhost
- Environnement : `http://localhost:3000`
- Page principale : `/property/add/home`
- Objectif : montrer comment créer manuellement une annonce de maison à louer
- Règle : ne pas utiliser l'assistant IA dans cette vidéo
- Règle : ne pas produire la vidéo tant que ce script n'est pas validé

---

## Intention

Cette vidéo doit répondre simplement à la question :

> "Comment je publie une maison à louer sur Trouve Ton Nkama ?"

On montre le parcours manuel complet :

1. ouvrir la page de création d'une maison ;
2. ajouter les photos ;
3. remplir les informations principales ;
4. renseigner les caractéristiques ;
5. choisir la localisation ;
6. ajouter le contact ;
7. publier l'annonce.

Le message doit rester simple :

> "Vous remplissez les informations étape par étape, puis vous publiez."

---

## Données d'exemple

Annonce utilisée pour la démonstration :

- Type : `Maison`
- Statut : `À louer`
- Titre : `Maison à louer à Alenakiri`
- Description : `Maison à louer à Alenakiri avec 2 chambres, 1 salon, 1 cuisine, douche et WC interne. Située en voie secondaire, dans un quartier accessible.`
- Superficie : `120`
- Prix : `140000`
- Province : `Estuaire`
- Ville : `Owendo`
- Quartier : `Alenakiri`
- Informations complémentaires : `Voie secondaire, accès facile.`
- Contact : `077413382`
- Nombre d'étages : `1`
- Nombre de salons : `1`
- Nombre de garages : `0`

---

## Parcours Validé

### Étape 1 — Introduction

But : annoncer le sujet.

Action écran :

1. afficher une carte courte avec le logo ;
2. texte écran : **Vous avez une maison à louer ?** ;
3. sous-texte : **Publiez votre annonce sur Trouve Ton Nkama** ;
4. rester environ six secondes.

Voix off :

> "Vous êtes propriétaire d'une maison et vous cherchez à publier une annonce de location ? Vous êtes au bon endroit avec Trouve Ton Nkama."

Overlay :

> **Maison à louer**

Durée : 6 secondes.

---

### Étape 2 — Ouvrir la page maison

But : montrer qu'on est dans le bon type d'annonce.

Action écran :

1. ouvrir `http://localhost:3000/property/add/home` ;
2. attendre que la page soit chargée ;
3. montrer le haut du formulaire ;
4. ne pas cliquer sur l'assistant IA.

Voix off :

> "Pour publier une maison, ouvrez la page de création d'annonce maison."

Overlay :

> **Maison**

Durée : 6 secondes.

---

### Étape 3 — Ajouter les photos

But : montrer que les photos sont la première chose à ajouter.

Action écran :

1. montrer le bloc **Sélectionnez plusieurs images** ;
2. cliquer sur **Ajouter des images** ;
3. sélectionner quelques photos de démonstration ;
4. attendre que les miniatures apparaissent.

Voix off :

> "Commencez par ajouter des photos claires du logement."

Overlay :

> **Ajouter les photos**

Durée : 10 secondes.

---

### Étape 4 — Remplir les informations principales

But : montrer les champs essentiels de l'annonce.

Action écran :

1. remplir le titre ;
2. remplir la description ;
3. remplir la superficie ;
4. remplir le prix ;
5. choisir **À louer** ;
6. mettre en valeur le champ **Votre rôle sur ce bien** ;
7. sélectionner **Propriétaire direct** pour montrer que l'annonce pourra afficher le tag propriétaire direct ;
8. cliquer sur **Suivant**.

Voix off :

> "Renseignez les informations principales. Pensez aussi à préciser votre rôle sur le bien : en choisissant propriétaire direct, l'annonce pourra afficher ce tag."

Overlay :

> **Infos principales**

Durée : 18 secondes.

---

### Étape 5 — Renseigner les caractéristiques

But : montrer que les champs changent selon le type de bien.

Action écran :

1. montrer l'étape des caractéristiques ;
2. remplir **Nombre d'étages** ;
3. remplir **Nombre de salons** ;
4. remplir **Nombre de garages** ;
5. cliquer sur **Suivant**.

Voix off :

> "Pour une maison, ajoutez les caractéristiques comme les étages, les salons et les garages."

Overlay :

> **Caractéristiques**

Durée : 12 secondes.

---

### Étape 6 — Choisir la localisation

But : montrer la localisation par province, ville et quartier.

Action écran :

1. montrer le bloc **Localisation du bien** ;
2. sélectionner la province **Estuaire** ;
3. sélectionner la ville **Owendo** ;
4. sélectionner le quartier **Alenakiri** ;
5. attendre que la localisation soit stable.

Voix off :

> "Choisissez ensuite la province, la ville et le quartier du logement."

Overlay :

> **Localisation**

Durée : 14 secondes.

---

### Étape 7 — Ajouter le contact et publier

But : montrer l'action finale.

Action écran :

1. remplir les informations complémentaires ;
2. remplir le numéro de contact ;
3. cliquer sur le bouton final de publication ;
4. attendre le retour visuel de succès ou la redirection vers les annonces.

Voix off :

> "Ajoutez les informations utiles, le numéro à contacter, puis publiez l'annonce."

Overlay :

> **Publier**

Durée : 12 secondes.

---

### Étape 8 — Conclusion

But : finir avec la marque.

Action écran :

1. afficher une carte finale avec le logo ;
2. afficher le nom de la plateforme ;
3. afficher **Disponible sur tonnkama.com**.

Voix off :

> "Trouve Ton Nkama. Publiez vos annonces sur tonnkama.com."

Overlay :

> **tonnkama.com**

Durée : 6 secondes.

---

## Notes importantes

- Faire la vidéo en vue mobile.
- Ne pas utiliser l'assistant IA dans cette vidéo.
- Si le bouton assistant IA apparaît, ne pas attirer l'attention dessus.
- La voix off doit suivre les actions à l'écran.
- Les champs doivent être remplis lentement, sans précipitation.
- Les photos doivent déjà être prêtes dans un dossier avant de tourner la vidéo.
- Si la publication crée une vraie annonce, utiliser une annonce de test ou supprimer l'annonce après la capture.
- Prévoir une vidéo 09 séparée pour montrer la création avec l'assistant IA.
