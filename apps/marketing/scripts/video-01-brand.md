## NOTES DE PRODUCTION

### Captures d'écran à préparer
- [ ] Page /search avec 6+ annonces visibles (beau contenu)
- [ ] Filtre mobile ouvert sur province + ville sélectionnée
- [ ] Carte interactive avec 5-8 pins visibles sur Libreville
- [ ] Card d'annonce avec badge "Propriétaire direct" visible
- [ ] Page détail annonce propre avec photo + prix + bouton contact
- [ ] Logo Trouve Ton Nkama (SVG/PNG haute résolution fond transparent)

### Couleurs motion design
- Fond principal : `#146B67` (vert Tonnkama)
- Texte : `#FFFFFF`
- Accent/highlight : `#1FA89B`
- Fond problème (acte 1) : `#000000`

### Texte overlay — typographie
- Titres : Bold, 64-72px
- Sous-titres/descriptions : Regular, 40-48px
- Police recommandée : Inter ou Poppins

### Transitions
- Entre captures : glissement horizontal rapide (0.2s)
- Acte 1 → Acte 2 : flash blanc brutal (cut)
- Acte 2 → Acte 3 : fade vers fond vert

### Format export
- Résolution : 1080 × 1920
- FPS : 30
- Format : MP4 H.264
- Destinations : Facebook Reels, Instagram Reels, WhatsApp Status
