# Vidéo 5 — Accès plateforme
**"Comment accéder à Trouve Ton Nkama"**

- Format : 9:16 vertical, 1080 x 1920 px
- Durée cible : 30 à 40 secondes
- Type : vraie capture mobile de l'app en localhost
- Objectif : répondre simplement à la question : comment accéder à la plateforme ?
- Règle : valider le script avant de produire la vidéo

---

## Intention

Cette vidéo ne doit pas expliquer les filtres ni le parcours complet de recherche.

Elle doit seulement montrer :

1. comment trouver Trouve Ton Nkama depuis Google ;
2. comment accéder plus vite avec l'adresse directe ;
3. arriver sur la plateforme.

Le message doit être simple :

> "Vous pouvez accéder à Trouve Ton Nkama depuis Google ou directement avec tonnkama.com."

---

## Scénario

### Étape 1 — Question d'ouverture

But : accrocher les personnes qui demandent comment accéder au site.

Action écran :

1. afficher une carte courte avec le logo ;
2. texte à l'écran : **Accéder à la plateforme**
3. rester 2 secondes.

Voix off :

> "Voici comment accéder à Trouve Ton Nkama."

Durée : 3 secondes.

---

### Étape 2 — Accès depuis Google

But : montrer la méthode la plus naturelle.

Action écran :

1. ouvrir une page Google simulée ou un navigateur ;
2. cliquer dans la barre de recherche ;
3. taper lentement `Trouve Ton Nkama` ;
4. afficher les résultats ;
5. cliquer sur le résultat `tonnkama.com`.

Voix off :

> "Première méthode : ouvrez Google et tapez Trouve Ton Nkama."

Overlay :

> **Google : Trouve Ton Nkama**

Durée : 9 secondes.

---

### Étape 3 — Accès direct par l'adresse

But : montrer la méthode la plus rapide.

Action écran :

1. revenir sur la barre d'adresse ;
2. taper `tonnkama.com` ;
3. valider ;
4. laisser la page d'accueil s'afficher.

Voix off :

> "Vous pouvez aussi aller plus vite en tapant directement tonnkama.com."

Overlay :

> **tonnkama.com**

Durée : 8 secondes.

---

### Étape 4 — Arriver sur la plateforme

But : montrer que la plateforme est ouverte.

Action écran :

1. laisser la page d'accueil s'afficher ;
2. faire un petit mouvement de scroll ;
3. revenir vers le haut pour montrer que l'utilisateur est bien sur la plateforme.

Voix off :

> "Une fois la page ouverte, vous êtes sur la plateforme."

Overlay :

> **Trouve Ton Nkama**

Durée : 8 secondes.

---

### Étape 5 — Fin simple

But : annoncer la suite sans surcharger.

Action écran :

1. afficher une carte finale avec le logo ;
2. afficher le nom de la plateforme ;
3. afficher **Disponible sur tonnkama.com**.

Voix off :

> "Trouve Ton Nkama. Disponible sur tonnkama.com."

Overlay :

> **Disponible sur tonnkama.com**

Durée : 7 secondes.

---

## Notes importantes

- Ne pas montrer la création de compte.
- Ne pas expliquer les filtres.
- Ne pas entrer dans le parcours de recherche : cette vidéo sert seulement à montrer comment accéder à la plateforme.
- Ajouter le logo au début et à la fin.
- La voix off doit être synchronisée avec les actions.
