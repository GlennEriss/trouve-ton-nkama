# users/phone-verification

Module feature-based pour la verification OTP du numero de telephone.

## Scope

- statut de verification (`phoneNumberVerified`)
- envoi OTP Firebase (`signInWithPhoneNumber`)
- confirmation OTP + persistance Firestore
- synchronisation session NextAuth apres verification

## Structure

- `services/`
- `hooks/`
- `ui/v1/`
- `__tests__/`
