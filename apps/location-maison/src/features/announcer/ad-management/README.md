# announcer/ad-management

Module feature-based pour la gestion des annonces annonceur (`/property`).

## Structure

- `services/` : acces donnees et actions annonce
- `hooks/` : orchestration UI/state (filtres, pagination, actions)
- `ui/v1/` : composants de presentation
- `__tests__/` : tests unitaires/integration (a completer)
