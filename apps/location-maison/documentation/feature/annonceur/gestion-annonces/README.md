## Perimetre

Cette feature couvre la refonte de la page annonceur `/property` pour:

- consulter efficacement ses annonces
- rechercher et filtrer ses annonces
- piloter l'activation, l'edition, la suppression et la promotion
- visualiser des statistiques annonceur utiles a la decision

## Hors perimetre

- creation d'annonce (wizard `/property/add`) hors refonte de cette phase
- refonte des pages detail annonce (`/property/[id]`) hors parcours liste
- paiement credits complet (documente dans le domaine credits)
