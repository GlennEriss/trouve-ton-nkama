# Vision Produit - Dashboard Admin Trouve Ton Nkama

## Pourquoi ce dashboard

Le produit public `location-maison` a besoin d'un back-office spécialisé pour centraliser les opérations admin sans dépendre de scripts manuels.

## Vision

Créer un cockpit admin unique qui permet de:

- superviser la santé de la plateforme
- gérer les utilisateurs et annonceurs
- modérer les annonces et contenus
- piloter les crédits, transactions et remboursements
- inviter d'autres admins selon des rôles précis

## Résultats attendus

- Réduire le temps de traitement des opérations sensibles
- Réduire les erreurs humaines liées aux manipulations manuelles
- Augmenter la visibilité sur l'activité de la plateforme
- Mettre en place une gouvernance claire des accès admin

## KPIs de succès (MVP)

- Temps moyen de traitement d'un ticket support
- Temps moyen de modération d'une annonce
- Nombre d'actions admin traçables (audit coverage)
- Nombre d'incidents liés aux permissions
- Délai d'onboarding d'un nouvel admin

## Hors périmètre initial (MVP)

- Refonte UX du front public `location-maison`
- Automatisation IA avancée de support
- Reporting BI avancé multi-source (phase ultérieure)
